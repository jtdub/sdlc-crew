# Backlog

This file is the work tracker for this project. The `sdlc-crew` workflow reads it
and writes to it. You can also edit it by hand.

Each work item has an ID such as `LOCAL-1`. Start the workflow on an item with
`/sdlc-crew LOCAL-1`, or with a plain description such as
`/sdlc-crew "Add a page that lists my recipes"`.
